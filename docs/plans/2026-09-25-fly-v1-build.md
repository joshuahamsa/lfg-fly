Status: written 2026-09-25 (autonomous overnight run, operator asleep). Follows
the approved design (`docs/specs/2026-09-22-fly-design.md`, §3.1–§5). Phase 0
passed (Gate A); Phase 0b was a diagnostic and is on record. The LFG side

**Goal for tonight:** the fly exists end to end. It has a critic-trained taste

signs in to LFG as an ordinary `agent` user, and a testnet rehearsal on staging

operator-driven (§5.4) and is not attempted.

## Tracks

### T1. The critic (spec §3.2) — `lfg_fly/teacher/critic.py`, `.claude/workflows/critic.js`
1. Round 1 pairs: `make_pairs(cat, 1000 families × 3, seed=2000)`; the same
   sampler as Phase 0 (40/30/30 looks, 60/40 near/far), seeds disjoint from
   the probes (0, 1000).
2. Cards: 1024×512 PNG, A left / B right, composited from the cached 512² layer
   thumbs in `trait_config.yaml` z-order (pinned commit), first frame of GIFs.
   Written to `FLY_DATA_DIR/mainnet/renders/critic-r1/`.
3. QC schedule: 10% of pairs shown again swapped (position bias), 10% judged
   again by a second agent (agreement). Main items batched 40 per agent (75
   batches); flips and dups in their own batches (15), so no agent ever sees a
   pair twice.
4. The workflow: one agent per batch, reads every card, returns
   `{item_id, winner, strength 1–3, idea_A, idea_B, reason}` per item and writes
   `results/<batch>.json`. The rubric is §3.2's (appeal, idea, surprise), forced
   choice, no rarity or price shown.
5. Assembly: `data/critic/r1.jsonl` (canonical orientation; flip and dup
   verdicts attached), `data/critic/r1-looks.json`, and the QC numbers: flip
   rate, agreement *a*, implied ceiling (1+√(2a−1))/2. Pairs the critic flips
   on are dropped from training.

### T2. Training and REPORT.md (spec §3.3, §3.4) — `teacher/train.py`, `brain/readout.py`, `brain/checkpoint.py`
1. Simulate every round-1 look with the Phase 0 brain (`rate`, g_syn 1.0,
   bias 0.1, 60 steps, `all-sensory-brain`, g_in 2.0) at c_ref; features are the
   2,129 readout neurons.
2. Taste head: Bradley–Terry logistic regression with the critic's strength as
   the sample weight, L2 by 5-fold family-grouped CV, ≥20% of families held out,
   family bootstrap CI (2,000). Standardization stats stored with the weights.
3. Controls on the same held-out pairs: one-hot + pixel-stats LR, MLP (256),
   rewired twin, sign-shuffled twin, eyes-only and nose-only brains, ≥5-synapse
   graph (if `graph-syn5` builds in time). Paired family-bootstrap differences.
4. Gate B: CI lower bound > 0.55. Best-of-6 is round 2 (not tonight unless
   round 1 finishes early). `REPORT.md` states every number, controls
   included, whichever way it falls.
5. `checkpoints/fly-v1/manifest.json` + `taste.npz`: everything §2
   "Checkpoint and versioning" lists.

### T3. The body (spec §4) — `lfg_fly/body/`, `lfg_fly/voice/`
- `client.py`: aiohttp client for the public API (sign-in with the `agent`
  provider + RegularKey proof, nfts, economy, rarity/supply, layer, equip,
  harvest, closet, brix claim, sign requests, logout). Token in memory only;
  logout in `finally`.
- `signer.py`: RegularKey signer with §4.3's policy table and a `simulate`
  pre-flight; refuses anything not in the table.
- `chain.py`: §4.4 chain identity (network_id + ledger-32570 hash, public
  endpoints only, fail closed).
- `legality.py`, `candidates.py`, `decide.py`: every legal single-slot Builder
  change + stay; taste (c_ref) and rarity (live) simulations; score =
  taste + β·rarity − λ·cost; temperature 0.15 with the date seed; ≤3 greedy
  steps; 30-day tabu.
- `records.py`, `reconcile.py`, `loop.py`: record before submit; the reconcile
  table (done / failed / UNKNOWN); UNKNOWN stops the loop with an outbox alert;
  per-network stamps refused on mismatch.
- `setup.py`: keygen, faucet (testnet), set RegularKey, BRIX line, Closet
  accept, mint donors (spend cap), harvest.
- `voice/`: naming by nearest critic-named look, before→after card, outbox
  (no X credentials tonight).
- `cli.py`: `setup`, `move [--dry-run]`, `claim`, `retrain`, `reproduce`.
- Tests against a fake LFG API (aiohttp test server) for every §7 "Body" bullet.

### T4. Testnet rehearsal on staging (spec §5.3)
1. `AGENT_SIGNIN_ENABLED=1` in `~/LFG-staging/.env`; `pm2 restart stg-activity
   --update-env` (the spec's rollout step 3; an `.env`-only change).
2. Fly testnet wallet: faucet-funded; RegularKey generated on the box and set by
   script; seed in `FLY_DATA_DIR/testnet/wallet.json` (chmod 600, outside every
   repo).
3. Donors minted through staging's mint flow (client-signed), harvested; hero =
   a mutable male. Spend cap `FLY_SETUP_MAX_XRP`.
4. `fly move --dry-run` → record reviewed → `fly move` on staging; post to the
   outbox.
5. Anything the staging stack can't do tonight (BRIX claims need the §5.3
   prerequisites) is recorded as not exercised, not as passed.

## Order and parallelism
T1.1–1.3 first (they gate the long critic run), then the critic workflow in the
background. T2 code and T3 code are built while the critic runs (independent
files; T3 in a Workflow with one agent per module and an integration pass).
T2 runs for real when `r1.jsonl` exists. T4 after T3's tests pass.

## Guard rails
- Nothing touches mainnet. No mainnet key exists. `fly move` refuses
  `network=mainnet` without `FLY_ENABLED=1`, which is not set.
- The connectome wiring is never changed; only readouts are trained.
- Every report number is on held-out families with a CI; controls are reported
  beside the fly, including when they beat it.
- No Claude attribution in commits or GitHub text (operator rule).
